# content/mappings/

Regulatory crosswalks. One subdirectory per regime:

- `nis2/`        EU NIS2 articles
- `dora/`        EU DORA RTS
- `cra/`         EU Cyber Resilience Act
- `gdpr/`        GDPR articles relevant to security operations
- `iso27001/`    ISO/IEC 27001 / 27002 controls
- `soc2/`        SOC 2 trust services criteria

Each mapping links control objectives to `../controls/` components and to
the playbooks that exercise them.
